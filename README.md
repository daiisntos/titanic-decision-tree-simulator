#  Titanic: Análise Preditiva e Simulador Interativo

Projeto desenvolvido com base no clássico desafio do Kaggle "Titanic – Machine Learning from Disaster", utilizando conceitos práticos de Ciência de Dados e Machine Learning aprendidos na formação da **SoulCode Academy**.

##  Sobre o Projeto
O objetivo foi investigar os fatores determinantes para a sobrevivência no naufrágio do Titanic utilizando uma Árvore de Decisão (`DecisionTreeClassifier`). Além da modelagem estatística, foi construído um **simulador interativo** no Google Colab com parâmetros dinâmicos (`#@param`), permitindo testar cenários hipotéticos de passageiros em tempo real.

##  Tecnologias Utilizadas
* Python
* Pandas & Scikit-Learn
* Google Colab & Widgets Interativos (`#@param`)

##  Principais Resultados
* Limpeza e tratamento de dados (tratamento de valores nulos e mapeamento de variáveis categóricas).
* Foco nas *features* mais relevantes (`Pclass`, `Sex`, `Age`), eliminando ruídos.
* Validação cruzada com acurácia média de **80%**.
